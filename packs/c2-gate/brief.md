A sample called Pebble was detonated in a sandbox, and its command server is long gone. Before it vanished, the analysts took one capture of the first exchange and recovered a few strings from the binary.

We rebuilt the server. It lives at your own instance link (start it below), and it behaves like the original: it only talks to the real implant, and it shows everyone else a boring web server.

Check in as Pebble, follow where the server sends you, and collect the tasking. It hands out a decryption key for the next stage. Submit that key as the flag.
