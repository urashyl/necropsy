A finance workstation sent an HTTPS request to a font-hosting domain every ten minutes. EDR kept the file that was making them, the network team kept one captured beacon cycle, and we put the operator's server back up. It is a real server running in an isolated container, started just for you. Start it below.

The file is a loader around an implant, and what the implant sends is not readable: every message is encrypted and authenticated, and the server answers only a client that gets it exactly right. There is no canned reply to fish for. Unpack the sample, work out the protocol and the key, then play the infected workstation against the server, from check-in to the end of one job.

The operator's server tells the implant something it should not. Submit it as the flag. The key is different for every player, and nothing here can reach the internet.
